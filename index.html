Three things to know

You see before anything changes.

Smart Scan only reads. It lists Windows settings, storage, startup items, Defender status, backups, drivers and crash history, with a plain-word note on each item. Every change shows what it will do first.

Undo is built in.

Restore points, an undo for startup and privacy switches, a backup of registry entries before any are removed, and a Removed-by-Suture list for preinstalled apps. A few Windows repair tools cannot be undone from Suture; the button says so first.

Private by design.

It reads system information on your PC and does not send it to us. No account, no analytics, no telemetry. The few things that use the network (Windows and Microsoft tools it starts) happen only after you open or press them, or as steps of Smart Scan and Full audit.

How it works

  1. Install and scan. Run the installer (no administrator rights needed). Open Suture and press Smart Scan. It only reads.
  2. Read the findings. Each item explains itself in plain words, with the Windows page to fix it by hand if you prefer.
  3. Choose what to change. In Suture Pro, press the fix for an item, read what it will change, confirm. Items that need administrator rights show the normal Windows permission prompt first.

What Suture is not

Suture is not an antivirus and does not replace one. It uses Microsoft Defender, the antivirus built into Windows, for scans, and it lists unusual startup items for you to review. An item Suture lists is not necessarily malware.

Registry cleaning usually has little or no effect on speed or stability, and Microsoft does not support registry cleaners. Suture offers it only as an optional step: it lists entries that point to files that no longer exist, saves a backup first, and lets you undo with one click. If you are not sure, leave them.

Suture's summary score is a rough overview of what a scan found. It is not a measurement of speed or safety. Suture does not promise any change in speed or security.

Questions

Is Suture safe to run?

It reads first and changes nothing until you click. Each change says what it will do, and most can be undone. The installer adds no service, no scheduled task, no startup entry and changes no Windows setting. No software is free of faults: make a restore point first (Suture can make one) and keep your own backups.

What is your refund policy?

30 days from purchase, by email to suturesupport@gmail.com with your order reference. In the EU you may also have a statutory 14-day right of withdrawal, which can be lost once the download or key is delivered if you agreed to that at checkout. Details are on the refund page.

Can I use one licence on 1 PC, or on 3 PCs?

A 1-PC key is for one PC. A 3-PC key is for up to three PCs. All must be owned or controlled by you. Suture works offline and cannot count PCs, so this is a term of the licence that you accept, not something Suture enforces. A new PC, a reinstall or a Windows reset works with the same key: paste it in again.

I lost my key. What do I do?

Write to suturesupport@gmail.com from the address you ordered with and quote the order number (or the licence reference on the Licence page in Suture). We send the same key again. We do not make a second key for one order.

Which updates are included?

Your key unlocks Pro in every 1.x version of Suture, including all later 1.x updates. A future 2.0 may be a separate paid upgrade; your key keeps working in 1.x. Today new builds reach you as a new download.

What data does Suture read, and does it leave my PC?

It reads Windows settings, Defender status, startup entries, services, installed apps, drivers, event logs, battery and disk information, file names, sizes and dates in the folders you point it at, and the location tags inside photos in your private folder. It reads file contents only on your PC and never uploads them: photo tags, the duplicate finder (SHA-256 of files over 1 MB), the threat hunter's file check (the first 1 MB of files it inspects) and files you ask Defender to scan. None of it is sent to us. See the privacy page.

Which version of Windows does it run on?

Windows 11, 64-bit (x64). Windows 10 support is being tested and is not promised yet. It runs under emulation on Windows 11 for ARM, which has not been tested.

Windows says "Windows protected your PC" or "Unknown publisher". Is something wrong?

The current build is not code-signed, so Windows has no publisher name to show and warns about it. This warning is about the missing signature and how few people have downloaded the file; it is not a verdict on the file. To check that the file is the one we published, compare its SHA-256 value:

Get-FileHash -Algorithm SHA256 "SuturePro-Setup.exe"

Run that in PowerShell in the folder you downloaded to. The result must match this value exactly: the SHA-256 value published next to each download. If it does not match, do not run the file and write to us. If it matches, choose More info, then Run anyway.

Will it change how fast my PC runs?

We make no promise about speed. Suture shows what it found and lets you make changes. Some, such as fewer startup items, can change how a PC feels, but we do not measure that and make no claim about it.

Do I need administrator rights, and how do I uninstall it?

To install and to scan: no. Some actions (Windows firewall, Defender settings, scheduled backup, repairs, all-users startup entries) show the normal Windows permission prompt first. To uninstall: Settings, Apps, Installed apps, Suture, Uninstall. The uninstaller asks whether to keep your settings, logs, quarantine and backups. Windows settings you changed through Suture stay changed unless you use Undo in Suture first.

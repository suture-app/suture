What Suture changes on your PC

The full list, kept in step with the product. It also ships with the installer.

Suture only changes something when you click the button for that change. Nothing below happens by itself, except the first section (the installer) and, if you switch it on, automatic mode switching in Modes. Items that need administrator rights show a normal Windows permission (UAC) prompt first. "Undo" means a button inside Suture puts it back.

3. Programs Suture starts

  • suturewin.exe (its window, built from native\suturewin.cs) uses the Microsoft WebView2 runtime that Windows already has. If the runtime is missing, or the host cannot start, Suture opens a Microsoft Edge "app" window instead; Edge may then show the page address (127.0.0.1) while the page loads. The shipped host and helper are checked against bin\SHA256SUMS every start; if a file differs, Suture builds its own from the source in native\ with the csc.exe that comes with Windows (into %LOCALAPPDATA%\Suture\bin).
  • suturehelper.exe reads battery and power state while the Battery page is open, and stops a minute after the window goes quiet.
  • Windows PowerShell (powershell.exe, hidden window, the scripts in ps\) does the reading and fixing. A warm PowerShell worker (about 90 MB) is kept for a few minutes while the window is open. It is started with a script file and receives its work over a pipe; nothing is downloaded or run from the internet.
  • Administrator actions: Suture copies the exact script into an administrator-only folder, checks its SHA-256, then runs that copy. If a script's hash differs from the pinned one it is refused.
  • A hidden local server on 127.0.0.1 only (never reachable from the network), protected by a random token per session. It exits about two minutes after the window closes.

5. What leaves your PC, and when

Suture sends nothing to its maker. No account, no telemetry, no advertising, no update check of its own. The Windows and Microsoft tools it starts contact the internet only in these cases, after you open the page or press the button (Smart Scan and Full audit include some of them):

  • App updates page and Smart Scan: Microsoft's package manager winget talks to Microsoft's package sources (it refreshes the list at most every 6 hours of use). Suture sends a HEAD request to the download address winget printed, to show the size, and downloads the installer itself from the app maker's site when you press Update (checksum checked where the maker publishes one).
  • Network page and Full audit: pings to 1.1.1.1 and 8.8.8.8 and one DNS lookup. Failure doctor connection test: 1.1.1.1 on port 443, your router and a Microsoft connectivity name.
  • Windows Update page and Smart Scan: Windows' own update service, which receives the client name "Suture" with the search. Defender definition update: Windows Security contacts Microsoft.
  • Deep analysis of a crash dump (only after you confirm): Microsoft's public symbol server receives the name, version and identifier of every program and driver module in the dump. The dump file is not uploaded.
  • Vendor driver links open in your browser; Suture does not download drivers.

With "backgroundNetwork": true in config.json (default false) the Network and App updates pages are read in the background; leave it off for no background contact.

6. Uninstall

Settings > Apps > Installed apps > Suture > Uninstall. The uninstaller asks Suture to quit (it never ends a process), removes the program files, shortcuts, the sign-in tray entry, %LOCALAPPDATA%\Suture (host, WebView2 and Edge profile caches) and the Edge fallback profile, then asks whether to keep your settings, logs, quarantine and backups. If the scheduled tasks or %ProgramData%\Suture exist, it asks once for Windows permission to remove them. Windows settings you changed through Suture are not undone by uninstalling: use Undo in Suture first. Silent uninstall (for IT): unins000.exe /VERYSILENT keeps your data and never raises a permission prompt; add /DELETEDATA to remove the data (including the licence key and trial record), and /REMOVEADMINITEMS to also remove the scheduled tasks and %ProgramData%\Suture (one Windows permission prompt). The backup folder C:\SutureVault is removed only with both switches (or by answering Yes in the normal uninstall).
